# FinSight

Projeto de engenharia de software voltado à análise e ao processamento de dados financeiros utilizando Python, SQL e serviços da AWS.

## Objetivo

Desenvolver uma aplicação capaz de processar dados financeiros, validar informações e disponibilizar resultados para consultas e análises.

## Tecnologias

- Python
- SQL
- Git e GitHub
- AWS S3
- AWS Glue
- AWS Athena
